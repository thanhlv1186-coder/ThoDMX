# Dashboard Kinh Doanh · DV GHLĐ Thợ ĐMX

Dashboard React (Vite) — 6 tháng cuối năm 2026. Chọn phạm vi Toàn quốc / theo Vùng, bản đồ Việt Nam, và công cụ Import dữ liệu từ Excel.

## Chạy thử tại máy
```bash
npm install
npm run dev
```

## Đưa lên GitHub & deploy Vercel
1. Tạo repo mới trên GitHub, push toàn bộ thư mục này lên.
2. Vào https://vercel.com/new → Import repo → Vercel tự nhận Framework = **Vite**.
3. Bấm **Deploy**. Xong sẽ có link `*.vercel.app`.

Build: `vite build` → thư mục `dist`.
